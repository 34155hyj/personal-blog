# 首版项目计划

本页保留首版范围与里程碑。后续新增功能与实际验收见 [交接报告](HANDOVER.md)。

## 1. 背景

需要一个低成本、高性能、能长期维护的个人站点，用来沉淀科研笔记、知识整理与项目记录。现有博客平台要么绑定账号与广告，要么改版成本高；自建动态站点又需要服务器与数据库。静态站点是折中方案：写 Markdown，构建成 HTML，托管在免费平台。

## 2. 目标

1. **长期可维护**：内容与代码分离，换主题、加页面不影响已有文章。
2. **低成本**：零服务器、零数据库、零付费接口，可托管在 Cloudflare Pages 免费额度内。
3. **阅读体验优先**：排版、公式、代码、目录、深色模式、移动端都要可用。
4. **可交接**：文档齐全，后续 AI 代理或他人能直接接手。

## 3. 第一版范围

### 包含

| 模块 | 内容 |
| --- | --- |
| 首页 | 站点介绍、内容统计、最近更新、标签、精选项目 |
| 博客 | 列表 + 详情，支持标签、分类、上下篇 |
| 科研笔记 | 列表 + 详情，结构同博客 |
| 项目 | 列表 + 详情，含状态、技术栈、外链 |
| 知识花园 | 按种子 / 生长中 / 常青分组，卡片详情 |
| 标签 | 索引 + 单标签聚合页 |
| 分类 | 索引 + 单分类聚合页 |
| 归档 | 按年份倒序 |
| 关于 | 占位页，个人信息待填写 |
| 404 | 自定义页面 |
| 通用能力 | 响应式、深色模式、KaTeX、Shiki、TOC |

### 不包含（明确排除）

- 数据库、用户注册、登录、评论
- 全文搜索（后续可加 Pagefind）
- RSS / Atom（后续可加 `@astrojs/rss`）
- 图片上传后台、CMS
- 访问统计、广告、付费 API
- 多语言
- 真实科研内容的填充（由站主自行完成）

## 5. 验收标准

对应任务书第 8 条：

1. 本地开发服务器可正常运行。
2. `npm run build` 成功，`dist/` 生成完整页面。
3. 核心页面无 404、无模板报错。
4. 桌面（≥ 1280px）与手机（375px）尺寸下布局正常。
5. 新增 Markdown 文件无需改代码即可出现在站点。
6. 仓库内无硬编码密钥、token、私人联系方式。
7. 文档完整，可交接给 Codex。

## 6. 风险与应对

| 风险 | 应对 |
| --- | --- |
| Node 版本与最新 Astro 不匹配 | 锁定 Astro 6.4.8（要求 ≥22.12.0），不追 7.x |
| 第三方依赖失效 | 仅用 Astro 官方集成 + 两个成熟 remark/rehype 插件 |
| 内容越写越乱 | 四类集合 + 标签/分类双层组织，frontmatter 强校验 |
| 后续接手者不熟悉 | AGENTS.md + ARCHITECTURE.md 写清约定 |
| 示例内容被误读为真实成果 | 所有示例 `example: true` + 正文声明 + 页面徽章 |
